# Portafolio — Jesus Juarez

Portafolio personal con estética de "sistema de archivo": fondo generativo, modo día/noche, hoja de personaje con experiencia laboral y música ambiental sintetizada en vivo.

**Sitio:** https://jesusdre.github.io/portafolio/

## Estructura

- `index.html` — estructura de la página
- `styles.css` — estilos y temas
- `data.js` — todo el contenido (perfil, experiencia, proyectos)
- `main.js` — interacción y animaciones
- `audio.js` — música generativa y efectos de sonido (Web Audio)

Sitio estático sin dependencias ni build. Para verlo localmente:

```bash
python3 -m http.server 5173
```
